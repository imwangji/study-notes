读懂 Nielsen 的 Network 类

初始化、sigmoid 与 feedforward · 整理自一段 55 分钟的自学录屏（Michael Nielsen《Neural Networks and Deep Learning》第一章）· 配图为视频中手写板的截图

一句话总结
Network([2, 3, 1]) 做了两件事：初始化时为每个非输入层随机生成偏置和权重；feedforward 时把输入一层层往后算，每层都是 a = sigmoid(w·a + b)，最后得到整个网络的输出。
class Network(object):
    def __init__(self, sizes):
        self.num_layers = len(sizes)
        self.sizes = sizes
        self.biases  = [np.random.randn(y, 1) for y in sizes[1:]]
        self.weights = [np.random.randn(y, x)
                        for x, y in zip(sizes[:-1], sizes[1:])]

    def feedforward(self, a):
        for b, w in zip(self.biases, self.weights):
            a = sigmoid(np.dot(w, a) + b)
        return a

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

1. 出发点00:00

神经网络是解决分类问题的一种手段，遇到分类问题就可以想到它，就像做网站会想到 MVC。这一节的具体问题是识别手写数字。讲者给自己定的规矩：对代码的理解必须当场记下来，否则很快就忘。

2. sizes 与 biases01:20

[2, 3, 1] 表示输入层 2 个神经元、隐藏层 3 个、输出层 1 个。sizes[1:] 是"跳过第一个，剩下全要"，得到 [3, 1]，因为输入层不需要偏置。

np.random.randn(y, 1) 生成 y 行 1 列的随机矩阵，所以 biases 是一个列表，按层装着两个数组：3×1 和 1×1。

3. zip 与切片07:40

sizes[:-1] 去掉最后一个得 [2, 3]，sizes[1:] 去掉第一个得 [3, 1]。zip 把两个序列按位置配对成 [(2, 3), (3, 1)]，于是循环两轮：x 是上一层的神经元数，y 是下一层的。

4. weights：两层之间的连接11:45

np.random.randn(y, x) 生成 y 行 x 列：第一轮是 3×2，第二轮是 1×3。讲者的疑问是：网络明明是 2、3、1，权重怎么一个像"六饼"、一个是一行三个？

答案：神经元数量描述每层有几个值，权重描述上一层每个神经元怎么连到下一层每个神经元。2 个连 3 个，就是 6 条线。

⚠️ 讲者中途想错、后来自己更正上图是"每个输入节点保存自己发出去的 3 个权重"。44 分钟让 AI 用假数字打印后更正：矩阵是横着存的，每一行属于一个接收方神经元。weights[0] 的 3 行对应 3 个隐藏神经元，每行 2 个数是它从 2 个输入接收的权重。形状写成 (y, x) 正是为了后面能直接算 w·a。

5. 回顾感知器22:00

讲到 sigmoid 时发现它和"神经元"有关，于是先复习感知器：接收 N 个二进制输入，产生 1 个二进制输出；权重是实数，表示各输入对输出的重要性。

加权求和就是每个输入乘以自己的权重再相加。

⚠️ 算例更正视频里口算时说得有些乱。按手写板上的数字 x=(1, 0.5)、w=(0.8, −0.2)，正确结果是 1×0.8 + 0.5×(−0.2) = 0.7。

为什么还要阈值？加权和是一个连续的数，而感知器要做的是替人做决定，需要"是 / 否"。

⚠️ 阈值和偏置视频里两个词混用。它们是同一件事：令 b = −阈值，条件"w·x > 阈值"就变成"w·x + b > 0"。

6. sigmoid32:30

神经元先算 z = w·x + b，再算 a = σ(z) = 1 / (1 + e−z)。a 才是神经元的真正输出，在 0 到 1 之间。例：σ(1.1) ≈ 0.75。

⚠️ 为什么 sigmoid 只有一个参数 z？讲者以为至少要有输入、权重、偏置三个参数。其实是两步：先由 np.dot(w, a) + b 算出 z，再对已经算好的 z 做变换。sigmoid 只负责第二步。z 是数组时逐元素计算，一次算完一整层。

7. feedforward36:45

zip(self.biases, self.weights) 按层配对：第 1 轮拿到 3×1 的 b 和 3×2 的 w，第 2 轮拿到 1×1 的 b 和 1×3 的 w。每一轮都是用当前层的输出算出下一层的输出。np.dot(w, a) 是矩阵乘法：w 的每一行和 a 逐个相乘再相加。

h1 = σ(w11·x1 + w12·x2 + b1)
h2 = σ(w21·x1 + w22·x2 + b2)
h3 = σ(w31·x1 + w32·x2 + b3)
输出 = σ(v1·h1 + v2·h2 + v3·h3 + b)
⚠️ 讲者最后没解开的问题："a 在 for 循环里是一直在增加吗？"不是累加，是每一轮被覆盖：上一层的输出就是下一层的输入。

两个细节：输入要写成 (n, 1) 的列向量而不是 (n,)；返回值严格说是 1×1 的数组，不是"纯数字"。
